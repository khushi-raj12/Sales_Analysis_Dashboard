# Sales Analysis Dashboard

## Project Overview
This project analyzes sales data using SQL and Power BI to identify sales trends, customer insights, product performance, and regional performance.

## Tools Used
- SQL
- Power BI
- CSV Dataset

## Features
- Total Sales
- Total Customers
- Total Products
- Total Orders
- Sales by Category
- Sales by Region
- Sales by Product Name
- Sales by Segment

## Files
- sales_dashboard.pbix
- sales_data_clean.csv
- queries_data_sales.sql

## Key Insights
- West region has the highest sales.
- Furniture category generated the highest sales.
- Consumer segment contributes the largest share of total sales.
